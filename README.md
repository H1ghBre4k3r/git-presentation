# git-presentation
Git Presentation OE 2025

## GitHub Pages

This repository is configured to deploy to GitHub Pages automatically. The `index.html` file in the root directory will be served as the main page.

### Deployment

The site is automatically deployed using GitHub Actions whenever changes are pushed to the `main` or `master` branch. You can also trigger a manual deployment using the "Actions" tab in GitHub.

### Setup Requirements

To enable GitHub Pages for this repository:
1. Go to the repository Settings
2. Navigate to "Pages" in the left sidebar
3. Under "Build and deployment", select "GitHub Actions" as the source

Once configured, the site will be available at: `https://<username>.github.io/git-presentation/`
